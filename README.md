# DSA in Python
Data structures and algorithms practice, written from scratch in Python.

## Contents
- Searching: linear and binary search, rotated array problems
- Trees: BST, TreeMap, traversals, balanced BST
- Hash Tables: custom hash table with linear probing, HashMap class
- Sorting: bubble, insertion, merge, quick sort
- Dynamic Programming: LCS, knapsack, edit distance (recursion, memoization, DP table)
- Graphs: adjacency list/matrix, BFS, DFS, Dijkstra
- Leetcode_solutions: numbered problems with complexity notes

## Approach
Each problem has a header with time/space complexity and the approach,
test cases written before coding, and brute force before optimised.
